# PrintPilot

Aplicativo para Windows que prepara, visualiza e imprime etiquetas e documentos PDF, com perfis de impressora, monitoramento de pastas e histórico local.

## Download

Baixe o instalador em [Última versão](https://github.com/eduardojsc18/PrintPilot-App/releases/latest). Escolha o arquivo `PrintPilot-Setup-<versão>.exe` em **Assets** e execute-o no Windows x64. O instalador inclui o runtime necessário.

## Atualizações

A partir da versão 0.41.0, abra a interrogação **Sobre o PrintPilot** e clique em **Verificar atualizações**. Se houver uma versão mais recente, veja as novidades e clique em **Atualizar agora**. O aplicativo baixa e verifica o instalador, fecha para instalar e abre novamente. Configurações e histórico são preservados. Aguarde o preparo/envio de impressão terminar antes de atualizar.

Versões anteriores precisam instalar a 0.41.0 manualmente uma vez para receber esse recurso.

## Sobre este repositório

Este é o canal oficial público de instaladores e notas de versão. Não contém o código-fonte do aplicativo. Os arquivos “Source code” gerados pelo GitHub incluem apenas a documentação deste repositório.

## Dados locais

Configurações e histórico ficam no computador. A consulta de atualização acessa o GitHub, sem enviar etiquetas ou histórico. A conversão de ZPL utiliza o serviço Labelary por HTTPS.
